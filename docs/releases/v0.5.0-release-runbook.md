## 最终校验

```bash
python3 -c "import re, os
with open('README.md') as f: text = f.read()
for l in re.findall(r'\[.*?\]\((.*?)\)', text):
    if not l.startswith(('http', '#')) and not os.path.exists(l.split('#')[0]): print('Broken:', l)
"
```

## 发布命令

```bash
git checkout main
git merge feat/dear-agent-p0-p1
git tag -a v0.5.0 -m "release: v0.5.0 - 企业级 AI Agent 平台全新里程碑版"
git push origin main v0.5.0
```

推送 tag 后，`.github/workflows/release.yml` 将使用
`docs/releases/v0.5.0-agent-workspace-demo-draft.md` 自动创建正式 GitHub Release。
同时也可以在本地直接运行 `gh release create v0.5.0` 进行兜底发布。
