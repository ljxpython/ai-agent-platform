# v0.5.0 - 企业级 AI Agent 平台架构重构与生产级智能体里程碑

> 正式发布说明，将自动同步为 GitHub Release Notes。

## Summary

`v0.5.0` 是平台的重大里程碑版本：项目全面确立**“面向二次开发与企业落地的 AI Agent 平台底座”**定位，解耦平台治理层（FastAPI + PostgreSQL）与 Agent 执行层（LangGraph + GraphHarbor + Redis）；引入 3 套 Archify 2K 架构/时序/扩展点全景可视化系统；实装以 `open-swe`、`deepagents` 与 `deer-flow` 为核心工程支柱的生产级智能体 `DeerFlow Agent`，支持多模式工作流、长期记忆闭环引擎、安全沙箱 Workspace 与真实 PTY 交互终端。

## Highlights

- **企业级分层解耦架构**：平台治理层专职鉴权、多租户、审计与 Catalog 治理；Agent 运行时专职图编排与状态流转，两层通过受管契约通信，二开零侵入。
- **Archify 2K 架构与时序全景**：发布系统总览、Agent 请求执行链路、二次开发扩展点 3 套交互式可视化系统与 100% 完整长图。
- **生产级标杆 `DeerFlow Agent`**：支持探索/编码/分发多模式动态切换、跨会话长期记忆闭环（Memory Pipeline）、安全隔离沙箱（文件树与产物一键打包）及基于 xterm 的交互式 PTY 终端。
- **开源生态核心致谢置顶**：置顶致谢 `bytedance/deer-flow`、`langchain-ai/deepagents` 与 `langchain-ai/open-swe`，明确技术脉络与工程传承。
- **扩展协议全面就绪**：原生集成标准 Model Context Protocol (MCP) 与智能体复合技能包 (Skills)。
