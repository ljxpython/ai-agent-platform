# v0.6.0 - 持续评测飞轮、原生知识中台与全链路可观测工程全栈交付

> 正式发布说明，将由 GitHub Actions 自动读取为 Release Notes。

## Summary

`v0.6.0` 是企业级 AI Agent 平台的重大里程碑版本：
正式打通由**“执行-沉淀-出题-评测-质检”**构成的 **Agent 持续评测飞轮 (Continuous Evaluation Flywheel)**；全栈交付对标工业级排障体验的 **AI 网关综合使用看板 (Gateway Usage)** 与 **平台内置运维排障智能体 (Platform Assistant)**；原生集成 **LightRAG 知识中台** 与 Canvas 2.0 力导向图谱工坊；全面实装 **W3C `traceparent` 分布式追踪与 Loki TSDB 毫秒日志排障中心**；前端全量通过 180 套测试套件与 1070+ 项 Vitest 单元测试，端到端工程韧性与二次开发支撑能力迈上全新台阶。

## Highlights

- 🔄 **Agent 持续评测飞轮 (Continuous Evaluation Flywheel)**：
  - **业务会话一键转用例**：日常业务会话直接转评测集，FastAPI BackgroundTasks 异步 202 调度（0.3s 极速响应）彻底根治前端 30 秒超时，任务完成后通过平台全局通知中心（🔔）一键直达。
  - **AI 辅助出题与全生命周期评测**：与 AI 协同修订题目、设定复杂分支用例与裁判指标；版本化题库独立资产解耦；支持多环境 Agent 受信连接绑定与真实跨机评测执行、裁判诊断全景复核。
- 📊 **全新 AI 网关使用看板与综合可观测 (AI Gateway Usage Dashboard)**：
  - 基于 Vue 3 + ECharts 原生重构，深浅双主题自适应。
  - 黄金三要素指标卡（吞吐量、P50/P90/P99 延迟分位数、错误率与精准成本核算）。
  - 时序桶自适应推导与防爆（1m/5m/1h/1d），支持 Token 堆叠、Prompt Caching 命中率与单请求 Token 均值走势。
  - **毫秒级穿透闭环**：图表 Tooltip 悬停下钻直接跳转 Logs 标签页，并一键调起底层 Trace 链路抽屉，从宏观趋势瞬间下穿至微观单请求 Span！
- 🤖 **平台内置运维与排障智能体 (Platform Assistant)**：
  - 基于单一 `create_agent` 原生架构，专职负责平台运行指标诊断、受管只读 SQL 查询、跨微服务 Trace 与结构化日志穿透排障。
  - 前端落地 Clean Architecture 整洁架构，提供全局浮动唤起抽屉、`BaseDrawer` 拖拽无级拉伸（580px ⇄ 960px）、一键宽屏、实时错误胶囊（Context Pill）、免手写理由专职审批卡（仅执行/不执行）与证据穿透二级抽屉。
- 🧠 **原生知识中台与 Canvas 2.0 图谱工坊 (Native LightRAG Studio)**：
  - 基于 LightRAG 架构深度自研原生化集成，Canvas 2.0 力导向图谱工坊支持节点聚焦与聚类探索。
  - 单向免隧道 Scoped HMAC 鉴权体系，告别脆弱反向穿透隧道，支持只读检索 MCP 插件。
- 🌐 **全链路分布式可观测与轻量日志中心**：
  - 跨微服务透传 W3C `traceparent`（`00-{trace_id}-{span_id}-01`），支持 MLflow / EvalFlow 原生全景追踪树与 Langfuse 双轨热切换。
  - 基于 Grafana Loki (TSDB) + Promtail 建立超轻量微服务日志中心（四容器常驻总内存仅 186.47MB），实现根据单一 `trace_id` 毫秒级对齐微服务调用日志流。
- 🛡️ **生产级工程韧性与生命周期治理**：
  - **全数据生命周期治理 (Retention Governance)**：30 天闲置自动续期、GraphHarbor post48 通用 TTL、Workspace 随会话级联安全物理清理，杜绝磁盘堆积。
  - **交互防倒挂与状态机收敛**：会话 Stop 取消后乐观消息幽灵消除与草稿安全回填、万帧 SSE 历史回放防误触（Replay Immunity）、三段式会话侧栏排版与并发度 3 批量删除队列。
