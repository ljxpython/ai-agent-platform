## 发布命令

### 推荐方式：Git Tag 触发 GitHub Actions 自动化发布

```bash
git checkout main
git tag -a v0.6.0 -m "release: v0.6.0 - 持续评测飞轮、原生知识中台与全链路可观测工程全栈交付"
git push origin main v0.6.0
```

推送 tag 后，`.github/workflows/release.yml` 将自动读取
`docs/releases/v0.6.0-agent-workspace-demo-draft.md` 生成正式 GitHub Release。

### 本地兜底方式：通过 gh CLI 直发

```bash
gh release create v0.6.0 \
  --title "v0.6.0 - 持续评测飞轮、原生知识中台与全链路可观测工程全栈交付" \
  --notes-file "docs/releases/v0.6.0-agent-workspace-demo-draft.md" \
  --verify-tag
```
