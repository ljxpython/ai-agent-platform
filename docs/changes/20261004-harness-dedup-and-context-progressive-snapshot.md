# Harness 去重与 CONTEXT.md 渐进式快照

## 背景

审查发现两个问题：
1. `AGENTS.md` 的「场景1/2/3」和「验证标准」章节与 Skill 内容重复，两处分开演进后必然漂移产生矛盾
2. `CONTEXT.md` 的「最后更新」已堆积 11 条密集流水账，违反「只保留当前有效信息」的原则

## 改动

### AGENTS.md

- 删除「场景1/2/3」的代码块/步骤详情，改为一行路由结论 + Skill 文件引用
- 删除「验证标准」章节（单/链路/治理三级验证要求），该内容在 `verify-change/SKILL.md` 里完整定义
- 在流程章节头部加说明：「各 Skill 的详细流程步骤、模板、踩坑记录见对应 SKILL.md，不在此重复」
- 净减约 60 行

### CONTEXT.md

- 「最后更新」改名为「最近改动」，只保留最新一条完整描述
- 新增「本月归并」区块：旧条目按月压缩成一行（月份 + 核心事项列表，50 字内）
- 更新维护规则，明确渐进式折叠机制：新条目写入时上一条折叠进「本月归并」，超过 2 个月的月份删除
- 125 行 → 70 行

## 影响文件

- `AGENTS.md`
- `docs/CONTEXT.md`
