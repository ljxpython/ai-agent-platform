# AI 工作流经验库

> 适用范围：AGENTS.md、Skills、Harness设计、文档结构、Worktree资源隔离与多会话发布协作。
> AI 读取时机：处理AI工作流/Harness改动、Worktree依赖/基础数据复用与隔离验收，或恢复多个会话共用的依赖发布任务前读取。

---

## [坑] 模板升级时旧文档未加废弃标注

- **场景：** 标准模板升级为多专题模板时
- **错误：** 只建了新子专题文档，旧 plan.md/tasks.md 原地保留，读者打开项目目录不知道该看哪个
- **正确：** 升级是原子操作——先在旧文档顶部加废弃提示，再迁移内容，最后 README.md 的"阅读顺序"列表成为唯一纲领
- **日期：** 2026-09-21

---

## [坑] implementation/ 被误用为进度来源

- **场景：** 链路/治理改动的实现过程中
- **错误：** 把查 implementation/ 当做了解项目进度的方式，tasks.md 不更新或更新不完整
- **正确：** tasks.md 是进度的唯一来源；implementation/ 只是细节档案，不做不影响进度判断
- **日期：** 2026-09-21

## [坑] Skill 用外部路径作为"参考实例"

- **场景：** 在 SKILL.md 里用 "参考实例: apps/xxx/..." 让 AI 自己去读某个目录来理解规范
- **错误：** 外部读者（包括新会话的 AI）不知道那个目录是什么、从哪来的，也不保证那个目录一直存在
- **正确：** 把判断标准和规范直接写进 SKILL.md，不依赖外部路径引用
- **日期：** 2026-09-21

---

## [坑] 阶段进度被写成 Final 后提前收工

- **场景：** 项目还有可在隔离环境推进的任务，同时真实链路环境未就绪
- **错误：** 把已通过的阶段测试写成 Final `partial`，列出剩余任务后结束答复
- **正确：** 先逐项推进所有不依赖外部条件的任务；未完成时证据只记 Phase。只有剩余项都需要用户提供明确条件或决定，才能记录具体阻塞并结束
- **日期：** 2026-09-26

## [坑] 多会话共用发布版本时重复抢包

- **场景：** 多个会话同时推进同一依赖的专项发布与验收
- **错误：** 并行抢同一个 post 版本、重复上传，或拿旧候选文件冒充最新正式包
- **正确：** 发布前确认另一会话已结束；恢复先核对专项状态、正式发布清单、仓库产物哈希和锁文件（本次为PyPI四产物）；已发布版本复用正式文件冷安装验证
- **日期：** 2026-10-07（用户批准）

## [坑] Worktree 共享安装目录导致源码串用

- **场景：** 多个 Worktree 并行开发，希望复用已有 Python/Node 依赖
- **错误：** 共用或软链接整套 `.venv` / `node_modules`；Python editable 安装可能导入另一目录源码，可写安装目录和构建缓存也会相互影响
- **正确：** 共享 uv cache / pnpm store，各服务、各 Worktree 按自己的锁文件独立安装，并核验应用实际导入路径；具体规则见 [Worktree 开发规范](../standards/worktree-development.md)
- **日期：** 2026-10-10（用户批准）

## [坑] HTTP 健康检查不能证明 Worker 隔离

- **场景：** 验收多套本地栈的任务、数据和 Workspace 隔离
- **错误：** 只检查 API 健康或 catalog，就认定后台 Worker 属于当前环境、不会串任务和文件
- **正确：** 独立配置 PG/Redis/Workspace，用真实 Worker 执行确定性探针，返回实际环境 ID 并读写各环境同名文件；停止一套后确认其余仍可执行，见 [三栈验收证据](../projects/20261010-worktree-local-stack/verification.md)
- **日期：** 2026-10-10（用户批准）

---

## [坑] 复制模型配置时保留源密文却更换了密钥

- **场景：** 新 Worktree 复用主数据库中的模型配置，同时生成独立模型 master key
- **错误：** 原样复制模型 API Key 密文，导致目标环境无法解密；为绕过问题共享主密钥又破坏密钥隔离
- **正确：** 使用源密钥解密、目标密钥重新加密，在目标事务中写入；源库只读，不生成明文 dump 或日志，解密失败回滚，见 [基础数据复用验证](../projects/20261010-worktree-local-stack/verification.md)
- **日期：** 2026-10-10（用户批准）

---

## [坑] 审计表非空被误判为复制了主库历史

- **场景：** 验收新 Worktree 只复制基础配置、不复制对话和审计历史
- **错误：** 启动或健康检查产生了新审计后，仍要求 audit_logs 绝对为空，把本环境正常记录当成源历史
- **正确：** 首次业务链路前核对未复制源审计 ID，区分源历史和目标新记录；其他历史表按检查时点验证为空，见 [三栈基础数据验收](../projects/20261010-worktree-local-stack/verification.md)
- **日期：** 2026-10-10（用户批准）
