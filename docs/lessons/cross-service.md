# 跨服务契约经验库

> 适用范围：Platform API、Runtime Service 与 GraphHarbor 之间的 HTTP 契约、Delegation、授权隔离和跨服务测试。
> AI 读取时机：开始处理跨服务契约或 Delegation 改动前按需读取。

---

## [坑] Delegation operation 测试依赖固定数量或索引

- **场景：** 新增或调整 Delegation `scope.operation` 枚举时
- **错误：** 用固定枚举数量、列表索引或连续切片推断测试边界；新增合法 operation 后，旧测试误报或把 operation 分类错位
- **正确：** 按 operation 名称集合和资源白名单断言；新增 operation 同时补充专属隔离测试，避免测试结构依赖枚举顺序
- **日期：** 2026-10-06

---

## [坑] 旧服务忽略条件字段会把 CAS 降为无条件写

- **场景：** 跨版本扩展 metadata 条件更新，旧服务可能接受请求但忽略未知字段。
- **错误：** 给普通 PATCH 增加条件字段就认定原子保护生效，或在新接口不可用时退回普通 PATCH。
- **正确：** 条件更新使用独立 URI，旧服务明确返回 404/405；比较、授权过滤和写入在同一数据库操作中完成，并验证并发与旧版本拒绝。
- **日期：** 2026-10-09；F07 收尾经验，用户已批准沉淀。
