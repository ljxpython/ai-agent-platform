## 新增经验的流程

1. AI 犯了错，用户纠正
2. AI（或用户）将教训蒸馏为 ≤4 行，格式：场景 + 错误 + 正确做法 + 日期
3. 判断级别：
   - 任何场景都会犯 → 写进 `AGENTS.md` 的「严禁行为」章节（≤10 条上限）
   - 特定服务/领域才会犯 → 写进 `docs/lessons/{domain}.md`
4. 如果是新 domain 文件，更新本索引文件的表格行
