# 使用项目知识库

## 查看资料与检索
1. 选择项目后进入“知识库”（`/workspace/projects/{projectId}/knowledge`）。访问需要 `project.knowledge.read`。
2. 查看文档及任务状态，必要时点击“刷新”。文档已经出现不表示已完成解析和索引，应核对处理结果。
3. 点击“检索沙盒 (Playground)”测试问题的命中情况，核对返回片段是否确实支持答案。没有命中时可说明资料名称与问题，请维护者确认资料状态和项目范围。
4. 需要原生文档或图谱界面时，可用“图谱控制台”入口；其可用性和权限由实际接入状态决定。

## 上传入口的当前限制
项目页存在“上传文档”和“确认提交入库”弹窗，但当前入口尚未接通实际文件提交。弹窗提示不代表文件已上传或入库成功。

需要入库时，请使用已接通并获准访问的知识中台原生入口，或请知识库维护者协助；最终以文档处理状态和检索结果为准。当前用户指南不承诺尚未验证的原生页面按钮和上传流程。

## 与平台助手的区别
这里存放业务知识。平台助手的使用指南是另外维护的少量操作文档，当前没有直接读取项目知识库全部正文的工具。希望业务 Agent 使用知识库时，还需要该 Agent 的 Graph 和工具已接通对应知识检索能力。
