# 模型、成员、通知与设置

## 模型与工具
项目中的“模型与工具”用于查看该项目可用模型和工具策略；平台管理中的“模型连接”管理全局连接，两者权限和作用范围不同。

普通成员没有模型或无法调用时，先核对所选项目和 Agent 模型，再请管理员检查可用范围及启用状态。只有获准管理员才能在对应页面编辑连接；密码和 API 密钥不应粘贴到聊天中。

模型 429 只说明请求受到限制，不能据此认定欠费。先核对运行最终状态和已有产出，已成功的运行不重复执行；失败且确认重复操作没有副作用后，再考虑稍后重试或切换可用模型。持续发生时让管理员结合实际证据检查速率、并发和额度。

## 项目成员与用量
项目成员入口位于项目详情的成员管理，获准管理员可管理成员和角色。看不到项目、Agent 或功能时，应先核对成员与功能权限。个人助手项目不提供额外业务授权。

项目“Token 看板”查看当前项目用量；平台看板需要平台级使用量权限。统计结果需结合页面时间范围与模型口径理解，不把 Token 数直接等同最终账单金额。

## 通知中心
工作区通知入口可查看任务完成、失败与告警消息，打开通知详情或其结果链接继续处理。会话转评测集完成后也从这里进入结果。

平台管理的“告警与通知”提供通知流水和渠道配置；有权限时可新增或编辑通知渠道并“保存并生效”。渠道地址属于敏感配置，不要发给助手。普通用户不需要配置渠道才能阅读已获准的站内通知。

## 个人资料
从个人资料入口管理自己的资料和头像；更改个人资料不会改变项目角色、会话归属或业务访问权。功能缺失时请说明具体页面和账号权限，由管理员核对。
