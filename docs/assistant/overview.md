# 平台与项目入门

平台用于选择和配置智能体、对话执行任务、使用项目知识库，并将获准会话转为评测资料交付 EvalFlow。功能和数据按项目及个人权限开放。

## 开始使用
1. 登录后进入工作区，从“项目”选择自己已加入的业务项目。
2. 在项目管理区打开 Agents、Chat 或知识库。需要评测时，从 Chat 的“转为评测集”或“从历史会话建评测集”提交资料，后续出题、编辑、发布和运行进入 EvalFlow；原“评测与改进”菜单已退役。切换项目后先核对页面项目名称，再操作数据。
3. 页面没有入口或提示无权限时，请项目管理员确认成员身份及相应功能权限；不要通过改网址绕过权限。

## 两类助手
- 项目 Agent：在项目 Agents 中配置，用于执行具体业务任务；Graph 决定执行行为，模型负责理解与生成。
- 平台助手：从工作区的助手入口打开，可解释平台用法、读取获准诊断、查询已接入且获准的只读数据库，也可聊天讨论。
- 没有业务项目时，平台助手可以建立个人助手项目。它不授予任何业务项目权限，也不能读取别人的私有会话。

## 能力边界
平台助手目前没有生产业务写工具、Shell 或执行沙箱，不会代替用户修改配置、部署或修复服务。它读取的是专门维护的用户指南，不会自动检索项目知识库的全部业务文档。

使用时只提供必要问题与编号，不粘贴密码、密钥或完整隐私资料。指南描述当前页面；页面未接通或资料不足的能力应明确说明，不能猜测按钮和结果。
