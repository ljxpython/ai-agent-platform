# 评测与改进

## 新建测试需求
1. 选择项目，进入“评测与改进”。提示未启用时，请项目管理员确认是否接入评测工作台。
2. 有执行权限时点击“新建测试需求”，填写名称、要验证的 Agent、问题和业务口径；需要时添加合成文件。
3. 核对资料并勾选虚构示例确认，点击“保存测试需求”。保存后形成可找回的工作项，不代表评测已通过。
4. 打开工作项，由获准管理员确认资料用途；检查 AI 建议的测试口径与风险，再按页面提示审阅方案和执行验证。不认可时先说明要修改的内容。
5. 查看运行结果、评分依据和失败样例。工具执行成功或 AI 评分高，不代表所有业务场景都正确。

查看需要 `project.evaluation.read`，新建或执行还需要相应的执行权限；页面上的资料授权与方案确认不能由助手代选。

## 从会话转为评测集
在有权访问的历史会话操作菜单选择“转为评测集”，填写评测集名称，核对选中的会话和资料用途并确认后提交。

看到后台处理提示后可继续其他操作；转换完成或失败会通过通知中心提醒。点击通知中的结果入口查看，成功时到 EvalFlow 审阅生成的题目与预期结果。原生评测页面可能需要单独登录，不能把平台登录视为所有页面都已登录。

提交受理不等于题目生成完成。若转换失败，保留错误与任务信息，先核对失败原因；不要反复创建相同任务。AI 生成的用例需要检查，不会自动成为已经验收的业务规则。
