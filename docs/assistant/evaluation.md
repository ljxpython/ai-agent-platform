# 会话转评测集与 EvalFlow

Agent 平台只保留会话资料转换入口。出题、AI 修订、手工编辑、发布、运行和诊断均在 EvalFlow 操作。原“评测与改进”、回答评价及“让 AI 帮我改进”入口已退役；打开旧评测地址时按迁移提示进入 EvalFlow。

## 选择和提交会话

1. 选择正确项目和 Agent，在聊天操作菜单点“转为评测集”提交当前会话。
2. 需要其他会话时，点“从历史会话建评测集”，按时间、执行状态筛选并翻页选择；历史列表也可勾选后批量“转为评测集”。每次最多 20 段，只能提交有权访问的会话。
3. 在同一个确认弹窗填写名称，核对会话和资料用途，再确认提交。功能未启用或缺少执行权限时，请项目管理员核对配置与权限；不要修改网址绕过。
4. 看到后台处理提示后可以继续聊天。资料送达或交付失败会通过通知中心提醒；成功通知打开准确的 EvalFlow 条目。

“资料已送达”只表示会话资料完成交付。若已由有权人员确认 AI 用途，可在 EvalFlow 查看异步出题状态；AI 可能仍在处理或失败，通知不表示出题、发布或运行成功。回执未知时重试同一请求，不要反复新建。

## 权限和资料用途

普通执行者可以交付自己的资料，不能自行批准 AI 用途或要求自动生成。获准管理者仍需明确确认用途，助手不能代选。管理员身份不代表能读取其他人的私有会话；如需管理者审阅这批资料，应由会话所有者显式分享该会话的读取权限，再由有权人员确认用途，避免扩大项目分享。

资料仍受源会话权限、用途、脱敏和签名校验。授权或运行失败时保留错误和任务编号，交由管理员核对；不要关闭权限校验或把业务资料复制到其他项目绕过限制。

## 在 EvalFlow 继续操作

审阅 AI 候选中的题面、预期、来源和评分方法，按需继续修改、采纳或手工编辑，再保存草稿。发布题库版本和运行版本分别确认，发布不会自动运行。结果中查看会话、评分和可用证据；AI 高分不代表所有业务场景正确。

当前本机 Agent 连接远端 EvalFlow 的开发环境中，资料交付、真实出题和发布已有验证；主动运行仍因跨机 Runtime 源码验真缺失而被阻止，不能承诺可运行。既定规则是已生成题库作为 EvalFlow 独立资产保留，来源授权到期不使题库自动失效；继续读取源会话和管理题库仍须各自权限，原始快照按自身留存规则处理。这项到期可用性仍待补验，不把题库永久保留等同原始资料无期限开放。登录提示以目标页面为准，不把平台登录视为所有原生页面都已登录。
