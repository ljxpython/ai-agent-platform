# 创建和配置 Agent

## 新建智能体
1. 先选择业务项目，打开项目管理的“Agents”，进入“创建 Agent”页面（项目路径 `/workspace/projects/{projectId}/agents/new`）。
2. 填写名称并选择底层 Graph。Graph 是执行逻辑，不是模型；只可选择当前项目开放的项。
3. 在“模型与推理参数”选择“指定模型”，或保留“使用项目默认模型”；按页面支持项设置生成参数和执行策略。
4. 检查工具访问控制与模型恢复策略，提交创建。看到“创建成功”后回到列表核对，再从 Chat 发起试用。

编辑已有 Agent 时，从 Agents 列表打开详情，修改后保存，看到“已保存修改”才算成功。没有需要保存的改动时页面会提示。

## 模型和工具
“模型恢复策略”可为临时模型故障配置重试或备用模型。发生过一次错误不代表运行最终失败，需要结合最终状态和重试结果。

工具列表由 Graph 声明并受平台、项目及用户权限约束，界面配置不能扩大后台授权。创建与修改需要 `project.assistant.write`；只有读取权限时不要尝试提交编辑。

## 定时执行
进入项目“定时任务”，点击“新建任务”，填写任务内容，选择 Agent、模型及页面提供的调度方式，核对时间与时区后点“立即创建”。已有任务可编辑并“保存变更”，也可暂停、恢复并查看运行历史。

定时任务写入需要 `project.runtime.write`。创建任务不表示它已经成功执行，应在运行历史核对结果。模型没有可选项时，请项目管理员检查“模型与工具”；不要把凭据发给助手。
