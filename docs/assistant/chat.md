# 聊天、历史和平台助手

## 与业务 Agent 对话
选择项目后进入“Chat”，选择可用 Agent，输入需求并发送。运行中可查看工具过程和输出；需要中断时使用停止操作，等状态确认停止后再发新请求。

历史列表用于重新打开有权访问的会话并继续追问。新建会话不继承其他会话的上下文；管理员身份不代表能查看别人的私有会话。

## 使用平台助手
1. 打开工作区平台助手，直接描述问题。普通聊天无需先选工具。
2. 询问页面怎么操作时，助手根据问题选取当前用户指南，读取最新正文后给出步骤。
3. 点击回答中的“证据”编号可查看工具结果、文档标题与行号。文档更新后原会话仍可使用，下一次操作咨询应读取新内容；历史答案不会被自动改写。
4. 抽屉中的“新会话”开启独立对话；历史入口可找回自己的助手会话。目前没有跨会话长期个人画像。

## 运行报错时求助
在运行错误详情中点击“向平台助手求助”，将本次错误上下文带入助手。尽量保留目标项目、Thread ID、Run ID 和 Request ID；不知道编号时先说明页面、操作和发生时间，不要编造。

前端错误分类只是初步提示。助手会读取有权查看的运行诊断，必要时读取目标运行附近的有限日志，并区分已确认事实、可能原因和下一步。没有日志、诊断未配置或限流，都不能单独证明业务失败根因。

助手本身不可用时，错误现场卡片会保留，可点击卡片上的“复制诊断”，或在原错误详情中“复制排障诊断包”，交给项目管理员或支持人员。复制成功不等于故障修复。

## 确认操作
出现审批卡时，核对动作与参数再选择“执行（确认）”或“不执行（拒绝）”。关闭窗口、超时和没有选择都不表示批准。平台助手当前没有正式生产写工具，不会替用户执行修复。
