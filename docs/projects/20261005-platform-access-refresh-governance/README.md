## 关键决策
1. 权限查询失败与权限确认拒绝必须使用不同状态和用户反馈。
2. 同一项目的权限刷新请求合并，局部 Thread 拒绝不得触发全局权限失效。
3. 网络故障不得清除登录会话；只有明确认证拒绝才执行会话过期处理。
4. 后端保留真实 ACL 回查，先优化作用域、连接复用和可观测性，不削弱撤权边界。
