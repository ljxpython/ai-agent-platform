# 项目详情与知识中台交互收敛 (Project Detail Knowledge Streamline)

## 项目概述
- **时间：** 2026-10-19 至 2026-10-20
- **目标：** 消除项目详情页与左侧一级导航「项目管理 -> 知识库」的功能重叠与认知混淆，将项目详情页的「项目知识库」定位收敛为轻量级看板概览，并提供一键直达知识中台的快捷通道。
- **负责人：** @lijiaxin (老王暴躁技术流督导)
- **模板类型：** 标准模板
- **状态：** done

## 改动范围
- **影响服务：**
  - `platform-web`：项目详情页 `ProjectDetailPage.vue` 与知识面板 `ProjectKnowledgePanel.vue`
- **改动级别：** 单项目改动（前端用户体验优化与交互收敛，跨页面认知规范化）
- **预计工作量：** 1 人天

## 关键决策
1. **单一事实中枢原则（Single Source of Management）**：
   - 知识库的完整管理、文档上传、入库解析排队、切片追溯、检索沙盒（Playground）以及 LightRAG 图谱控制台（9621）全功能，唯一归属于左侧主菜单 **「项目管理 ➔ 知识库」**（`ProjectKnowledgePage.vue`）。
2. **详情页降级为轻量看板与直达入口**：
   - 项目详情页保留「项目知识库」Tab 作为项目看板的一个维度，但彻底消除“到底在哪里管理知识库”的歧义。
   - 在面板头部增加明显的「知识中台导航引导卡」，展示底座在线健康状态与关键指标，并提供高亮按钮 **【进入知识库中台 ➔】**，点击即刻无缝路由跳转至全功能页面。
3. **保持测试契约与历史兼容性**：
   - 兼容既有 Vitest 单元测试与 Playwright E2E 测试选择器，不暴力破坏现有 DOM 骨架，平滑演进。
4. **路线 A：知识中台二级功能板块闭环（图谱工坊 + 智能问答）**：
   - 在主知识中台（`ProjectKnowledgePage.vue`）中，无缝接入「知识资产中枢」、「知识图谱工坊 (Graph Studio)」和「智能问答工作台 (Chat Studio)」三大二级板块。
   - 利用 LightRAG WebUI (端口 9621) 的租户与项目参数隔离机制（`tenant_id=__default&project_id=${projectId}`），沉浸式嵌入当前页面，既保持了项目上下文连贯，又兼顾了独立窗口全屏弹出的灵活性。
