## 关键决策（已批准）

1. 复用同步 SQLAlchemy、psycopg 和 Alembic，专用库建议 `platform_api`，使用独立角色；不合并 Runtime 数据库。
2. 推荐完整保留当前基线业务数据。清洗迁移或空库重建必须另行明确批准数据舍弃清单，不能默认丢弃审计和请求历史。
3. 正式本地及容器入口统一 PostgreSQL；SQLite 单元测试和迁移源读取保留，不强行重写存储层。
4. 停写、备份、导入、校验、只读验收后才开放写入；新写入后不能承诺切回旧 SQLite 无损恢复。
5. 本期交付本地及隔离容器验证、可复用迁移流程；实际生产库操作与发布须另定环境、窗口和授权。
