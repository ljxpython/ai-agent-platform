## 变更前核实

本地 Homebrew PostgreSQL 17.11；两个可登录角色为 lijiaxin（超级用户，无密码）和
platform_api（非超级用户，已有 SCRAM 密码）。现有 Unix socket、IPv4、IPv6 和复制认证均为 trust。
真实只读探测确认：两个业务库在缺密码、错误密码时均允许连接。

lijiaxin 拥有 12 个数据库（含 Runtime、维护库和其他项目/测试库）；平台另有独立 platform_api 库。
因此不能把全实例认证规则变更当成只影响 Runtime 的配置补齐。
