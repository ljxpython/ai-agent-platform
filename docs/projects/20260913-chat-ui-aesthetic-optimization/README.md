# 前端对话页面美化与交互体验重构 (Chat UI Aesthetic Optimization)

## 项目概述
- **时间：** 2026-09-13 至 2026-09-14
- **目标：** 彻底清除对话页面陈旧粗糙的“毛坯后台”视觉包袱，重构消息流、Hover 操作栏、工作台顶栏、Agent 空白引导页、代码/工具执行卡片及输入框微交互，达到现代化 AI 工作台的高级审美水准。
- **负责人：** 老王 (@laowang)
- **状态：** done

## 改动范围
- **影响服务：** `apps/platform-web`
- **改动级别：** 治理改动（纯前端核心页面视觉重构与交互升级，不改变后端契约与数据模型）
- **预计工作量：** 1~2 人天

## 关键决策
1. **消息操作栏去噪**：放弃每条消息常驻的大号表格按钮（`pw-table-tool-button`），改为现代 AI 对话标配的 `group-hover` 浮动极简图标工具栏，大幅降低视觉负担。
2. **顶栏控件去 Admin 化**：彻底移除原生 HTML `<select>` 凑数设计，封装高质感智能体选择胶囊；对功能按钮进行 Primary / Secondary 视觉分级，让工作台重心突出。
3. **消除硬编码与毛坯组件**：替换 `ToolResult` 中纯文本 `▾ / ▸` 字符，升级文件 Diff 与命令执行卡片为现代代码/终端视觉包装；美化思维链（Reasoning）容器。
4. **新会话沉浸化引导**：重构空会话展示，提供专属 Agent 欢迎卡与可点击快捷 Prompt 指令推荐，让空状态具备高互动性和专业感。
