# 介入与验证手册

## 目标
让新开发者能理解运行链路，在本地安全启动 Showcase，并知道提交前必须验证什么。

## 方案设计
覆盖：环境准备、目录导航、Context 与权限、线程工作区、Docker 执行、Graph 注册、流式/HITL 调用、测试标记、故障定位和变更记录。

## 任务拆分
- [x] 编写 15 分钟快速上手。
- [x] 编写本地运行、fake model、integration、live/e2e 命令说明。
- [x] 编写故障排查与证据收集表。
- [x] 补充变更记录和 FEATURES 同步规则。

## 验证要求与记录
- [ ] 干净环境可完成 import 和默认快速测试。
- [ ] Docker 不可用时能得到明确失败，不回退宿主机 shell。
- [ ] 至少一条审批恢复和真实文件产物链路有可复验证据。
