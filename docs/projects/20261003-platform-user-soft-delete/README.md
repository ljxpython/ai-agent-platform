## 关键决策
1. **状态软删除而非物理抹除**：扩展 `UserStatus.DELETED = "deleted"`，改名加随机后缀释放原始 `username` / `email` 唯一性约束，吊销所有会话 Refresh Token，既满足用户清理需求，又防止历史审计日志与运行时 Thread 发生幽灵外键断裂。
2. **三重安全栅栏（Guardrails）**：
   - 防误操作自杀：严禁操作者删除当前登录账号自身；
   - 防超管断代：严禁删除系统最后一个激活的超级管理员；
   - 防孤儿项目产生：如果目标用户是任意项目的唯一管理员（Sole Project Admin），拒绝删除并提示先移交管理员权限或删除项目。
3. **成员关系主动清理**：确认非唯一管理员后，自动移出其所在的所有项目成员记录（`project_members`），清理干净。
4. **列表默认过滤**：前端与后端默认查询自动排除 `deleted` 状态用户，操作菜单提供二次确认防误触弹窗。
