## 关键决策

1. 按官方公开协议和锁定源码实现，不重新实现Pregel、子Agent调度、私有状态机或事件SDK；langgraph-api只用于隔离对照环境，不成为GraphHarbor生产依赖。
2. 区分图内Event Streaming、Run SSE版本与线程Protocol v2；版本数字不做全仓库替换。
3. GraphHarbor仅处理通用运行事实与传输；Dear模式、技能、文件权限、业务输入留在当前项目。
4. 五种生命周期是合法事件集合，不是每次必走的五步；名称、错误及cause只携带实际存在的数据。
5. 先让显式v3和resume链路可靠，再切客户端默认；本轮不提前全站切v3，不要求删除v2。
6. 对外使用“冻结版本＋验收矩阵已覆盖的兼容范围”；矩阵未全通过，不宣称“完整实现官方v3”。
