# DearFlow Agent 前缀缓存实验与动态上下文评估

用户希望了解 Xiaok 的 DeepSeek 在当前 DearFlow 多轮任务中实际复用了多少输入，以及调整记忆、日期和工具定义的位置后，能否降低整项任务的费用或等待时间。实验结果将用于一篇可复核的缓存优化文章，保留没有收益和任务失败的结果。

**当前状态：部分完成（partial，用户已确认实验与文章，Task 10 合并及测试环境清理进行中）。** 独立 Worktree 已接入临时日期/记忆上下文，原 16 次官方小批对照完成，相关回归 180 项通过。新增 23 次官方多轮调用中，A 在第 4 轮旧偏好失败后停止；B 后置诊断八轮、11 次模型调用及三次真实读取通过，全量读取 **87.93%**，固定排除第一次模型调用后 **96.24%**。原定完整八轮 A/B 未完成，不能宣称完整任务同质量费用下降。新增八项离线测试通过，产品源码未继续改动。旧 97 次 Xiaok、16 次官方数据及失败保留；用户已批准本地合并及相关测试数据/数据库清理，唯一进度见 [tasks.md](tasks.md)，不包含远端推送或生产部署。

## 当前决定

首轮使用 Xiaok 的 `deepseek-v4.1-flash`，不纳入 Anthropic。已完成现状回放、单因素探索、独立重复和少量进程内完整 Agent 任务；请求/返回模型别名一致，底层部署与隐藏路由未知。后续官方批次固定官方主机及 `deepseek-flash`，使用用户提供的临时凭据，未复用 Xiaok Key。凭据仅进入单次执行进程，结束已移除并退出，用户可销毁。

五案例探索 32 请求、原线路核验 3 请求、重复 48 请求、日期任务 4 请求、摘要 2 请求、组合 8 请求，共 97 请求。按目录配置价合计估算 1.8859788 USD，实际扣费未知；各批次在调用前登记材料、规模与停止条件，没有为取得更好结果重跑失败任务。

不采用首轮个人记忆永久冻结或强制提前暴露全量工具。产品接线将每次调用的新日期和当前允许召回的记忆放在当前真实用户消息前，保留原消息、Checkpoint、PII、权限检查、裁剪和摘要。官方对照实际完成 8 请求回放，另各一个两轮完整任务、各四次模型调用，合计 16 次、零重试。日期、记忆及读文件有限断言通过；不能由少量任务代替全部角色语义、生产 ACL 或上线验收。

## 现有证据及限制

改造前源码确有记忆追加系统消息、UTC 日期拼接在基础提示词尾部的行为；本次已改为临时上下文。图表工具仍按规范读取状态暴露。实际缓存需通过供应商用量验证，不能从代码或公共前缀字节数直接推出读取比例。

C01 合成固定材料四请求的读取比例为 49.33%，不是生产统一基线。三次独立重复合并后，记忆候选读取比例 40.35%→49.09%、配置估算下降 12.55%；日期候选 20.76%→49.35%、估算下降 31.97%，但请求完成耗时中位数增加 6.45%。记忆一次重复更贵，不能据合并值承诺稳定收益。

完整日期任务 A 第二轮请求已含 2026-11-24，回答仍为 2026-11-23，因此停止且没有 B 数据。另一种问法的组合任务 A/B 有限断言通过、估算下降 22.54%，每组仅一个任务，不覆盖该失败。身份/记忆源是合成夹具，不覆盖生产 ACL 或三服务 E2E；摘要单事实正确但输出截断，不代表整体忠实性通过。

官方 16 次响应的原生缓存、标准字段与 SDK 解析全部一致，字段覆盖 100%；两组首次缓存都为零，后续能够读取缓存。固定材料在日期/记忆切换后的第三次请求，A 读取 1,792、B 读取 13,184 Token，是本次位置优化的主要观测。官方全部调用合计标价估算 0.022440552 USD，实际扣费未知；不与 Xiaok 合并计算优化率。只有一个 AB 块、合成身份/记忆、短时间模拟跨天，不代表长期或生产统一效果。

原 16 次官方固定材料/完整两轮任务的全量读取为 52.66%→73.75% / 53.63%→72.97%，固定排除各组第一次模型调用后为 70.20%→98.34% / 71.17%→96.82%；峰时标价估算分别下降 42.45% / 37.55%，完整任务首正文中位时间反而增加 31.01%。费用包含首次及全部调用，不将后续读取效率冒充完整任务省费。

新增多轮三批为检查器误判六次、修正后 A 真实旧记忆失败六次、失败后另行预登记 B 诊断 11 次，共 23 次、零 HTTP 重试，原生/标准/SDK 用量 23/23 一致。共同前四用户轮各六次调用，排除首次后 A/B 为 85.74%/96.06%，仅为质量不同的探索性诊断。B 后四轮的 React 更正、模拟跨天、记忆移除和历史汇总通过，不能补成原完整八轮 A/B 收益。实际发生在 10:36–10:44 UTC 谷时，全部峰时参考估算 0.016981176 USD、当时谷时标价估算 0.008490588 USD，实扣未知，误判成本也计入。

2026-10-30 的 [Xiaok 历史验收记录](../20261028-subagent-fanout-and-prefix-caching/verification.md#正式端到端结果)记载输入 461,189 Token、缓存读取 255,232 Token，读取比例约 55.34%；价格未知，正文质量仅覆盖原五项中的三项。这是历史观测，不是今天的基线、同质量优化效果或费用收益。
