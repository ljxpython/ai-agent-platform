# Dear Agent 前端专属模块实施记录 (F1/P1 纠偏与全面对齐)

- **实施日期**：2026-09-14
- **任务代号**：08/F1
- **参考依据**：`docs/projects/20260913-dearflow-agent/08-web-and-platform-contracts.md` 及 `frontend-handoff.md`

## 1. 纠偏背景与根因

在首轮交付中，由于过度精简手写了 `DearAgentPage.vue` 与 `DearAgentSession.vue`，导致：
1. 缺少一级 "Dear Agent" 产品结构，智能体 Skills/产物/记忆等矩阵未挂载；
2. 丢失了通用 Chat 已经沉淀的成熟能力（双视图切换、轨迹 DevTools、Hero 看板、时间旅行、模型切换等）；
3. 缺少 Agent 实体与 Context Hash 鉴权透传，导致向后端发消息无法正确获权与流式回复。

## 2. 核心重构与实施内容

1. **一级标题下的 Dear Agent 产品架构**：
   - 在 `src/composables/useNavigation.ts` 中注册 `Dear Agent` 一级菜单分组；
   - 在 `src/router/routes.ts` 挂载 4 个完整智能体二级能力入口：
     - `workspace-dear-agent`：对话工作台
     - `workspace-dear-agent-skills`：Skills 技能
     - `workspace-dear-agent-artifacts`：任务成果
     - `workspace-dear-agent-memory`：长期记忆
2. **完整 Chat 业务代码基线快照**：
   - 将成熟的 Chat 核心组件（`ChatSession`、`ChatThreadSidebar`、`useChatSession`、`trajectory` 等）完整复制到 `src/modules/dear-agent/` 作为独立基线；
   - 内部依赖全部指向本模块自身或通用 `services/`，实现 **0 依赖 `modules/chat`**，反向检查亦为 **0 依赖**，双向绝对物理隔离；
   - 完美保留主对话流无界布局、沉浸顶栏、轨迹排障 DevTools、时间旅行与附件能力。
3. **HITL 澄清提问卡片与输入锁定**：
   - 监听官方 `stream.interrupts` 中 `kind === "clarification"`；
   - 动态渲染 `ClarificationCard.vue` 表单；
   - `hasPendingInterrupts` 为 true 时，底部输入框强锁定，提交通过 `stream.respondAll()` 一键 resume 恢复执行。
4. **对话回复链路打通**：
   - `DearAgentPage.vue` 自动扫描并解析项目下 `graph_id === "dearflow_agent"` 的 Agent 实体；
   - 自动注入合法的 Context 配置，通过 Platform API 网关获取正确签发的受控 Run Token；
   - 流式响应管道全面打通，错误与状态即时透传。
