## 失败原因和边界

委派 1 漏请求派生前的时机；委派 2 漏随附 base 默认启用；委派 3 未明确父级已完成历史限定，另有 provider 计数及未读 prose 引用精度问题。详细评分、争议原句和来源核验见[37号](37-smoke12-and-v33-freeze.md)及数据文件。串行 3 写明父级已完成历史和进程外形态，但没有明确父 Agent 发现子级的结论，泛称服务“发现”不补齐该限定。

串行前两次最终抛出 `Missing validated ResearchSynthesis`，未交回合法最终报告。串行 2 先有 4 条格式反馈，不能把其全部过程解释为首次纯正文即失败。子级引用校验错误的纠错上下文丢失及主级纯正文提前失败均已用无网络 compiled graph 复现；应用修复和新证据单列[39号](39-validation-retry-correction.md)，不回写 v33 样本。

所有成功最终消息均恰一次且等于 checkpoint；串行失败样本没有合法最终消息，最终流验收不适用，不伪记通过。成功样本的 sources 字段行范围与实际已读窗口核对，完整坐标审计与语义完整性评分独立。目录简写假阳性、实际错误 prose 引用及 `operation=info` 被宽口径统计为无 ref 的情况均已保留并单列解释。
