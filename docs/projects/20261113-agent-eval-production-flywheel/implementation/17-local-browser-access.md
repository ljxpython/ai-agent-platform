## 用户遇到什么

## 查明的事实与处理

- HTTP客户端读取前端首页和脚本成功；用已有本地平台账号登录、读取正式工作项均返回200，工作项completed、revision5、2道题、5份草稿，原failed和后续passed两条结果仍在。读取响应约1.35MB，耗时约0.18秒。
- browser-skill在原地址复现导航超时。导航前启动的抓包仅记录初始Document请求pending，没有响应或脚本报错；这不能证明具体是缓存、扩展或网络栈问题。
- 使用所属Worktree的`scripts/local-stack.sh restart`受控重启EvalFlow前后端；重启完成，数据不清空。原主机名的浏览器异常仍复现，不能宣称重启修复。
- 将地址主机名改为`localhost`后，browser-skill实际加载登录页，使用同一个本地平台账号登录，完整打开原工作项：标题“11月退款核对-会话转换验收”、1段来源/8消息、2题、修订5及两条历史结果都可见。

`http://localhost:9138/#/authoring/ce53fafe-b375-5ebb-a932-bb9bcc422c3b`

当时的处理结论：**备用入口可用，但原127主机名的故障没有解决。** 这一结论已被下方的原地址恢复验证更新；不能把当时换主机名的操作说成修复。未清理用户浏览器缓存、Cookie或扩展，未操作用户标签页，未新增任何评测执行或调用模型。
