## 现在怎样操作

1. 在统一“评估运行”页的“评测任务历史”中选择任务。历史来自服务端保存的记录；完成、刷新或离开页面后仍可找回。
2. 点击该任务下方的“查看评测结果”“查看评测集”或“结果所属实验”，页面跳到真实归属位置。
3. 在统一“数据集”页的“授权批次评测集”中找题库，同一行可以打开最近运行。
4. 审核详情的“回流复现材料”默认展开，状态使用中文。发布后给出题库和本批运行链接；已发布记录不再提示尚需确认材料。

这些入口仅汇总后端允许当前用户查看的内容。没有搬迁题库、合并实验或放宽授权，也没有新增后端接口。
