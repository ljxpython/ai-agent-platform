## 本轮代码补齐

- EvalFlow `work_items.py` / `work_item_jobs.py`：按题列出信息缺口，允许批准其余题并记录排除项；反馈来源变化使旧批准失效，后台发布前复查。草稿即使未授权也受30天上限约束。
- EvalFlow `tasks.py` / `task_worker.py`：复用已有historical执行入口。新标准重评只接受同授权、同Agent/运行配置、同提问/附件/操作的旧证据。Task持久保存来源运行，不能用任意文件路径或新请求冒充旧证据。
- EvalFlow `scorers/agent_platform.py` / `gates.py`：事实因果、资料边界、建议依据分开评分，使用已批准rubric；各维不能互相平均抵消。逐轮确定规则同样不能被高分冲淡。模型每次请求前复查资料权限。
- 平台Web：结果页展开固定题库的实际选题；增加旧证据重评入口、从保存字段计算的版本差异、按状态分组和提交人筛选。未知回执刷新先对账，不重复提交。
- 平台API：解释结果时使用执行时批准标准，避免把旧AI草稿的“待确认”误说成执行时未批准；助手清理复查当前身份与来源权限，不能只看授权自身过期时间。
