# 工作区全量文件打包下载

## 项目概述
- **时间：** 2026-09-18 至 2026-09-18
- **目标：** 为工作区提供一键流式打包下载全部文件（.zip）的能力，避免前端递归扫描与内存溢出风险。
- **负责人：** @laowang
- **状态：** 已完成

## 改动范围
- **影响服务：** `runtime-service`, `platform-api`, `platform-web`
- **改动级别：** 链路改动
- **预计工作量：** 0.5 人天

## 关键决策
1. **后端标准库零依赖打包**：采用 Python 标准库 `zipfile` 递归遍历工作区物理目录，在内存流或临时缓冲区打包，杜绝第三方重量级依赖。
2. **网关流式安全透传**：`platform-api` 校验项目权限后通过 `RuntimeStreamingResponse` 透明透传 zip 二进制流，设置防嗅探与附件下载标头。
3. **原生浏览器下载体验**：前端 `WorkspacePanel` 提供醒目的打包下载操作入口，触发原生浏览器下载，体验轻快、无卡顿。
