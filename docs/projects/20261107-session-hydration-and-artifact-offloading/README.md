## 范围与硬约束

| 范围 | 本期职责 |
|---|---|
| platform-web | 复用 SDK 会话控制器，快照展示、事件对齐、媒体引用预览和按需历史查询 |
| platform-api | 复用 State/History/Workspace 接口及现有鉴权；仅补齐新引用所需的公开投影 |
| runtime-service | 工具媒体持久化引用、模型调用时解析、失败处理和 Workspace 生命周期接线 |
| GraphHarbor | 基线为 `0.13.0.post48`；当前方案不要求修改，始终保持通用 Agent Server 边界 |

1. **只覆盖新会话、新数据。** 不做存量会话修复、迁移、回填、双格式读写、旧逻辑 fallback 或旧版本读取新数据的兼容代码。新功能上线后创建的会话，在完成、刷新、重连后仍属本期范围。
2. **GraphHarbor 业务隔离。** 媒体识别、引用投影和平台策略留在平台 Runtime/API/Web。当前验证没有发现需要修改 GraphHarbor；若后续证明其存在通用缺陷，先提交复现证据与平台侧替代方案，再按 GraphHarbor 仓库规范单独评估最小通用修复。
3. **单一新路径。** 复用现有能力，只替换被本次设计取代的逻辑，不借机清理无关代码；不新增对象存储系统或通用兼容层。
4. **数据正确性与权限不裁剪。** 新数据的安全落盘、模型可读、审批恢复、取消、分支、子任务和权限撤销均需验证。
