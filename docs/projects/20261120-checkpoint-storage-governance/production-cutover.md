# 现役切换与独立目标恢复操作单

关联 P08。2026-11-21 当前仅完成只读预检，以下涉及生产备份外传、停写、安装、迁移和切换的步骤均未执行，执行前须取得对应明确授权。

## 目标与保护范围

目标为既有 SSH 运维入口 `sshmy1` 上的 `agent-runtime-api.service`、`agent-runtime-worker.service`，以及阻止新请求时短暂停止的 `agent-platform-api.service`。Runtime 现役库 `graphharbor_acceptance` 是业务库，绝不按名称判断为测试资源。预检为 GraphHarbor 双包 post48、LangGraph 1.2.11、Schema 014；执行前重新核对源码、真实进程及实际数据库，任何漂移都先停止并更新操作单。

目标源码固定为已合 main 且四项CI通过的 `5d3e241845f08a5d3618687d2c6a4159dda0a426` 及其 frozen Runtime 锁文件：GraphHarbor 双包 post50、LangGraph 1.2.24、Schema 015。仅切换 Runtime 代码与安装；不执行 Platform API 数据库迁移，不发布前端，不启用活跃会话自动 prune，不删除 runtime_events。GraphHarbor 四产物哈希见关联引擎正式发布证据。

生产仓库原有的两份锁文件改动、私有配置及部署脚本须先备份并记录哈希，禁止 reset/clean 覆盖。保留旧源码、旧独立安装与旧环境配置；恢复时仅改变已批准的目标绑定，不重置用户文件。

## 先验证独立恢复目标

现役根盘余约 18 GiB、可用内存不足 1 GiB，不在该机克隆约 10 GB 业务库或跑压力测试。可选的具体演练目标是本机私有独立 PG17 集群，目录由 `CHECKPOINT_RECOVERY_ROOT` 指向仓库外专用空目录，权限 0700，使用 OS 分配的空闲回环端口。开始前确认本机可用磁盘至少 40 GiB；演练只启动一套集群、一个恢复进程和一个验证进程，不启动模型 Worker、调度器、webhook 或生命周期维护。

生产备份复制到该目标同样需要授权。使用匹配 PG17 的 pg_dump，以一致性快照、自定义格式流式传输，避免在现役磁盘再留一份完整库。密钥不进入命令输出、文档或日志；不排除事件表等业务数据。备份完成后计算 SHA256，恢复到全新空库，以单事务/单进程执行；不得使用 pg_restore --clean 覆盖现役或已接收新写入的库。

以独立 post48/014 安装核对原线程、messages、checkpoint、writes、审批及任务数量/内容摘要；不执行工具和真实模型。再复制到第二个独立空目标，用 post50 升级 015，核对同一组摘要与 Schema。转换对无法证明 Run 归属的数据必须事务拒绝；不得为了通过演练删除问题行或关闭保护。独立恢复与迁移均通过后才允许安排现役停写窗口。首次备份/恢复总预算 30 分钟，超时终止所属子进程并保留来源库；这不是生产恢复时长承诺。

## 现役窗口

1. 再核对版本、私有修改、空间、活动 Run 与服务健康。暂停新请求入口并等待 pending/running 清零；存在不明执行、无法排空或预算不足则停止，不强杀业务 Run。
2. 停止上述三项服务，确认所属进程完全退出、数据库无应用写连接；执行最终一致性备份。旧独立恢复目标须来自这次最终备份，先以旧包/014 验证可读，再继续。
3. 将 Runtime 切换至已验源码和独立 post50 安装；先校验实际导入来源、双包版本和迁移 head，再执行 015。失败时停止，不启动旧包读取 015。
4. 先启动 Runtime API/Worker，核对真实 PID、015、旧线程/审批可读及就绪；再启动 Platform API。以专用验收会话验证两轮记忆、审批恢复、队列、取消、刷新/fork及跨项目拒绝，不修改旧业务会话。
5. 观察错误、内存、磁盘与 Run 状态，记录实际变化。短时通过不等于长期容量通过；现役约 10 GB 主体为 runtime_events，本项目不会自动回收它。

## 失败恢复与清理

015 是前向一次性转换，不能 downgrade。迁移或启动失败且没有新写入时，保留失败目标，绑定至最终备份验证过的独立 014 目标，并恢复匹配旧源码/包/配置；再核对三服务与旧会话。新版本已有写入时先停写并保全新目标，由负责人选择恢复目标与新写入处理方式，不能擅自覆盖或丢弃。

生产恢复备份在负责人确认稳定前保留，不纳入 P09 开发垃圾清理。独立演练结束后按所属句柄停止集群、删除专属恢复库/目录；保留脱敏校验摘要及备份保留位置的相对标识，不提交业务数据、凭据和原始日志。
