## 关键指标
- **工具返回上限控制**：`github_query`、`execute`、`search_web` 等工具单次输出字符严格收敛至安全阈值（默认 $\le 4,000$ 字符），超限自动溢出转存落盘为指针引用（Spill-to-Disk）。
- **重度长任务上下文稳定性**：在 60+ 次工具调用的重型任务中，上下文压缩触发次数从 6 次压降至 0~1 次，拒绝无脑反复二次/三次压缩。
- **有效信息保留率**：在压缩或截断过程中，核心事实、代码路径与结构化结论 100% 保留，杜绝失忆。
