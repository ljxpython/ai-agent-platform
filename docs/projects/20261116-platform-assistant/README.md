# 平台内置助手

用户在平台页面打开同一个助手，可咨询用法、聊天、讨论创意，也可把错误信息交给它。助手按当前权限读取数据库、运行诊断、日志和研发源码，给出证据、建议与未知项；读操作不反复确认，写工具必须逐次选择执行或不执行。

**当前批准开发与本地技术验收已完成（done）。** T01–T25均满足各自验收要求；2026-11-17追加的真实排障补强已实施并在当前本地Runtime生效。助手能读取目标Run的持久失败阶段，缺Trace时按后端验证的执行请求或Run查询日志，并准确说明当前可读资料。唯一任务进度来源为[tasks.md](tasks.md)，新旧范围的阶段验证与整体验收分别记录。生产未发布。

**真实排障补强结果：** 最终API96项、Runtime24项、证据抽屉5项及类型/指定静态检查通过；真实模型四轮、11个工具结果经引用断言和答案复核。已纠正review审批猜测、当前未配置推断历史未采集、空可读目录推断平台无数据库等错误。当前旧Run只读确认失败于`ExecutionSkillsMiddleware.before_agent`，错误码仍为泛化的`runtime.execution_failed`，底层根因未知。固定日志已接入，但对应旧时段未命中；不把0条、保留期未知或当前checkpoint无中断当根因证据。

**2026-11-17 新增结果：** 六篇短指南只讲当前前端用法，模型从人工目录选篇并读取最新正文；普通指南更新不再阻断旧会话。排障保留真实错误现场，按目标当前权限和运行时间取证，回答区分事实、推测、动作与缺证。真实浏览器验收还修复了跨项目Runtime委托不匹配、项目切换后旧异步结果污染新会话，以及明确403后清理受限内容并保留权限提示的问题；临时503仍保留现场。保留单Agent和只读工具，没有增加分词排名、向量库、Docker或发布流水线。

T12–T20按用户选择的当前环境，已用专用测试账号/项目完成真实GraphHarbor跨项目取证、追问、列表/重开、再次读取和撤权拒绝/屏幕缓存清理。当时最终助手API50、Runtime79、Web68项、类型与构建通过；真实模型13个场景及故障浏览器结果分别记录。扩大API回归142通过/3跳过/1既有Thread ACL断言失败，没有声称全仓通过。该阶段的临时模型连接及测试账号已停用，原临时凭据已替换，合成资料和审计保留；本轮T21–T25没有新建或修改模型连接。

本次采用一个 `create_agent`，不使用DeepAgents，不创建助手执行沙箱或shell。复用GraphHarbor持久历史、受管模型、预算、隐私、取消、流式协议及原生HITL审批。SQL复用LangChain SQLDatabase工具语义，Agent自行看结构并生成查询，Platform API负责独立只读连接与当前授权。当前数据库适配为PostgreSQL，可接多个获准数据源；其他引擎未实现。

所有登录用户可使用；无项目时幂等创建个人助手项目，不自动获得业务项目权限。使用指导优先内置/发布文档，源码只向明确获准研发开放。正式业务写工具为空，审批能力通过隔离测试工具验证，不虚构已交付业务修复动作。

真实链路已覆盖文档问答、自生成SQL关联聚合、同Thread续聊、重启恢复、新会话隔离、创意交流、结构化日志/源码、公开搜索、SSE和取消。另验证只读账号、权限撤销、旧历史/列表、查询与引用审计、跨进程审批及旧ID重放。具体测试结果、失败修复和已知基线测试问题见 [验证记录](verification.md)。

前端独立模块已落地于 `apps/platform-web/src/modules/platform-assistant/`，采用 Clean Architecture 独立解耦架构，包含全局抽屉、错误胶囊、独立审批卡、证据二级抽屉，详细协议与设计规范见 [前端开发交接](frontend-handoff.md)。
