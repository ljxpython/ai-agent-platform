# 平台内置助手

平台用户在操作页面遇到报错时，可以从错误弹窗点击“让助手分析”，或把复制的排障信息粘贴给助手。助手在用户获准的数据范围内查询数据库、运行诊断和日志，说明故障位置、依据、修正建议及尚不能确认的事项。用户也可以从全局入口咨询平台用法、查资料、聊天或讨论创意；使用指导优先引用当前版本文档，源码仅向获准研发开放。

助手采用create_agent加多类工具，运行在现有Runtime Service内，不使用DeepAgents或助手执行沙箱。Platform API负责授权和查询接入，历史与会话内记忆复用现有持久化；本期不新增跨会话长期个人记忆。

**本次交付为后端、Agent和前端开发交接文档。** 前端代码由同事实施，页面结构与组件复用由其决定。后端/Agent的组合根和公共组件由本次开发者选用；SQL优先复用SQLDatabase/SQLDatabaseToolkit，让Agent读取schema后自己生成查询。

## 当前结论与状态

**项目状态：部分完成（partial），方案和交接初稿已形成，功能尚未实施。** 2026-11-16用户已确认所有平台用户可用、数据权限分层、较广的数据库/日志/代码读取、数据库只读、文档优先和源码研发授权；随后明确本次只交付后端/Agent/交接，写工具必须由用户选择执行或不执行。已有批准继续有效；文档和方向批准不等于功能验收或生产授权。

当前已核对诊断包、运行诊断、日志查询、聊天会话和 Agent 组合根。现有日志路径存在认证放行及项目范围缺口；接入前需要审定具体读取范围和旧入口处理方式。详细批准记录与待冻结事项在 [plan.md](plan.md)，唯一任务进度在 [tasks.md](tasks.md)。

数据库查询不局限于固定问答：Agent按需看表/字段/关联，自行生成SQL，工具通过只读执行器查询并返回结果。开发者负责授权、只读执行和审计接线，不为每个问题预写SQL。正常读操作不弹确认；写入/修改/删除只能由单独暴露且授权的业务工具在用户点击“执行”后完成。未选择、拒绝、断网和超时均不能自动执行。本次验证审批机制，不凭空增加未指定的业务写动作。

## 当前基础与缺口

- 已有基础：错误详情和复制诊断包、Thread/Run 诊断、Loki 日志查询、聊天会话池、模型治理与追踪、知识检索装配。
- 本项目补齐：全局助手交互、查询工具、授权数据范围、关联校验、查询与证据使用记录、版本化文档/代码来源，以及真实联合验证。
- 既有能力的存在仅来自源码核对；本项目尚未执行应用测试、模型调用、数据库或生产验证。
