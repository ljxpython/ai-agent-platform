# 平台内置助手验证

## 验收原则与范围

本项目覆盖智能排障、使用指导、公开资料查询、聊天和创意交流，以及三服务接入、分层读取、数据库只读、源码研发授权和查询审计。唯一任务状态见tasks.md；本文件记录方法、实际结果和证据。

2026-11-16用户调整分工：本次负责后端、Agent及前端交接，前端实现/组件选择/浏览器验证由同事完成。原用户体验验收不删除，分别记录“本次后端交付”和“全栈联合验收”。新增必须验证持久历史/会话内记忆、无执行沙箱和写工具人工审批。

单元测试验证确定逻辑；真实数据源验证访问与只读边界；真实模型验证工具选择和回答质量；浏览器验证用户实际操作。任何一类不能替代其他类别，HTTP成功、健康探针和模型自述不能证明完成。

所有真实操作使用获准隔离环境，遵循docs/standards/worktree-development.md；测试前确认模型提供方、资料外发范围及额度。生产数据/凭据、部署、迁移和Git操作不从本方案自动取得授权。
