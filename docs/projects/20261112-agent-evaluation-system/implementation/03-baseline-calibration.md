## 真实运行结果

推理/裁判使用 xiaok `deepseek-v4.1-flash`，知识嵌入使用百炼 `text-embedding-v4`（1024 维）。三次 16 题开发集主动运行分别为 `5e7dd18e77eb4fbaaf5efc9cfe6df2e0`、`4b029b78ff004afa83b607261a01defb`、`ba34f0d8cfe84fb8ba5a6a76840c9646`。使用同一 comparison key 历史重评分后，门禁结果依次为 0、0、1；无评测系统错误。第三次唯一失败为 M01 `KnowledgeRetention`。该题整题 3 次中通过 2 次，指标均分 0.889、标准差 0.157。

4 题 holdout 最终重评分 `c117de021c144c45b4ced795a2da449b` 的门禁为 1，唯一失败为 M03 `KnowledgeRetention`（0.667）；C05、S04、G02 通过。裁判认为回答多复述了项目代号与操作限制。holdout 曾用于诊断裁判截断问题，因此不能称为完全盲测。该诊断没有用于调整 Agent Prompt 或评分阈值。

M01/M03 的失败理由把回答中对文件内容的复述当成额外事实，显示 KnowledgeRetention 裁判仍有误判风险。开发集已知质量 fail 被如实保留，门禁能检出失败只证明门禁工作，不代表 Agent 达到发布标准。
