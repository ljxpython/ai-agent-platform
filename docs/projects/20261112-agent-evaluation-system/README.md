- 一个 EvalFlow CLI 执行器、一个 Agent 平台适配器、两种执行模式（历史评分 / 主动回归）。
- `dearflow_agent` 作为主要被测对象；实际 graph / assistant 标识以 T00 目录查询为准；`showcase_demo` 仅可用于探针，不能替代代表性验收。

- 规则、DeepEval 语义指标、必要的自定义业务判定；评测失败与评测系统错误分别报告。
- 版本与配置快照、真实模型基线、已知故障检出、CLI 门禁和一次优化前后对比。
- Badcase 候选收集、人工审核入库流程、可复用指南与有证据的开发复盘。
