## 已确认的方案基线

| 事项 | 已确认结论 |
|---|---|
| 内置与自定义 | 内置技能只读展示，也允许用户上传自己的技能；上传不覆盖仓库内置 SKILL.md |
| 技能模型 | tenant + project + user + slug 下仅一份当前内容；内部 token 用于并发冲突控制，不做用户多版本体系 |
| 自定义管理 | 上传、显式更新、启用、停用、删除；保留包校验和正则阻断；只读审查不构成发布门槛 |
| 管理范围 | 用户＋项目隔离，不要求已有会话，不用“选第一个会话”作为替代 |
| 公共目录 | 动态枚举全部有效内置技能；不按内部用途或验收状态过滤 |
| 详情 | 公共与自定义均提供文件树、SKILL.md 和辅助文本按需读取；二进制不执行、不强行作为文本 |
| 运行生效 | 当前执行保持快照；新输入读取当前启用技能；中断恢复/同一逻辑执行重试沿用原快照 |
| 能力归属 | runtime-service 自有技能业务、存储及应用迁移；不向 GraphHarbor 加技能业务 |
| 迁移落地 | 自有 Alembic；`src/runtime_service/db/migrations/`；`python -m runtime_service.db upgrade`；独立 `runtime_app_alembic_version` |
| 旧接口 | 核查真实调用方，不需要的旧接口退役；当前前端确有调用，切换安排列入交接 |
| 存量 | 不做旧技能版本/绑定转换、双写或旧数据模型回切；不据此清空其他业务数据 |
