## 早期 UI 方案（非当前实施清单）

## 目标
解决 Skills 页面三个具体 UI 问题：治理上下文选择器样式糙、刷新按钮语义不明确、页面整体交互细节。

## 问题分析

### 问题 A：治理上下文选择器（会话选择）

**现状**：页面右上角有一个原生 `<select>` 下拉，用来选择"绑定哪个 Dear Agent 会话"的治理上下文。  
**图2截图显示的问题**：下拉展开后呈现原生浏览器样式，与系统整体的 Tailwind 设计语言完全不搭，且列表里有很多条目显示的都是 `"功能方案架构设计"` + 各种描述，视觉上非常嘈杂。

**设计逻辑解释**（这个设计本身有道理）：
- 自定义技能版本是**会话维度隔离**的——每个 Dear Agent 会话有自己的 skill 装配快照（freeze）
- 所以治理页面需要知道"你在操作哪个会话的技能"，这个选择器是必要的
- 但原生 select 的样式确实很不美观

**改进方向**：
1. 换成自定义样式的下拉组件（用 Headless UI 或手撸，与系统风格统一）
2. 或者考虑将"会话选择"移到页面的侧边栏或顶部面包屑位置，减少右上角的视觉噪音
3. 如果会话很多，需要加搜索功能

**补充问题**：从截图看，列表里有大量类似的条目（可能是同名会话），这是正常的 Dear Agent 会话列表，应该展示的是会话的 `metadata.title`，目前代码是 `t.metadata?.title || t.thread_id.slice(0, 8)`，所以如果用户没有设置 title 就会退化到 thread_id 前缀。

### 问题 B：刷新按钮的语义

**现状**：页面右上角有一个"刷新"按钮（`BaseButton`），点击调用 `fetchCustomSkills()`——从后端重新拉取自定义技能版本列表。  
**用户困惑**：不知道这个刷新是干什么的，刷新整个页面？还是刷新某个数据？

**改进建议**：
1. 加 tooltip 说明："重新从服务器加载技能版本状态"（或更简洁的表述）
2. 或者把刷新按钮改成更明确的形式，比如"同步状态"
3. 图标本身（refresh 图标）其实已经够清晰了，主要缺 tooltip

**注意**：刷新按钮的位置和"治理上下文"选择器在同一行，视觉上这两个控件关联性不够清晰（都在右上角的一个 div 里）。

### 问题 C：会话下拉是否在"平台公共技能"标签页也需要？

**现状**：无论当前在"平台公共技能"还是"自定义版本治理"标签页，顶部的会话选择器和刷新按钮始终显示。  
**问题**：在"平台公共技能"标签页，会话选择器和刷新按钮没有任何意义（公共技能与会话无关），但它们仍然展示，造成认知混乱。  
**建议**：在"平台公共技能"标签页时，隐藏会话选择器和刷新按钮（或将它们移到"自定义版本治理"标签页区域内）。

## 方案设计

### 整体思路

原先仅美化下拉的方案是纯前端改动，集中在 [`DearAgentSkillsPage.vue`](../../../apps/platform-web/src/modules/dear-agent/pages/DearAgentSkillsPage.vue)。本轮讨论的去会话化可能涉及后端契约。

### 治理上下文选择器改造

**推荐方案**：替换原生 `<select>` 为自定义样式的下拉，与系统其他 select 风格保持一致。需要先确认系统中是否已有通用的 BaseSelect 组件。

先检查一下：

> 待调研：`apps/platform-web/src/components/base/` 目录下是否已有 `BaseSelect.vue` 或类似组件？

如果有，直接复用；如果没有，按照系统风格撸一个简单的 styled select 即可（不需要完整 Headless UI，一个美化过的 `<select>` 就够了）。

**同时**：会话选择器和刷新按钮只在"自定义版本治理"标签页激活/显示（或 v-show，或移到对应标签内部）。

### 刷新按钮优化

在 `BaseButton` 的 `title` 属性加上清晰的说明：`"重新加载自定义技能版本状态（Agent 可能已通过对话更新了技能版本）"`

### 改动总结

| 改动点 | 改动类型 | 文件 |
|--------|----------|------|
| 原生 `<select>` 换为自定义样式 | 纯前端 UI | `DearAgentSkillsPage.vue` |
| 会话选择器仅在自定义标签页显示 | 纯前端条件渲染 | `DearAgentSkillsPage.vue` |
| 刷新按钮加 tooltip 说明 | 纯前端 UI | `DearAgentSkillsPage.vue` |
