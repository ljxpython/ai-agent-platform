## 执行、恢复与对话工具

- `apps/runtime-service/src/runtime_service/services/dearflow_agent/middleware/skills.py:21` 的 `ExecutionSkillsMiddleware` 扩展官方 SkillsMiddleware。
  新执行在 before_agent 中获取当前启用集合；根据 LangGraph 原生 execution_info.task_id 持久化幂等快照引用。
  这个 task_id 是执行节点标识，不以新的 HTTP run_id 代替逻辑执行身份。
- 引用保存在 PrivateStateAttr 的 `dear_skill_snapshot` 中，由既有 checkpoint 持久化，不能作为普通 graph input 写入。
  中断恢复从持久状态取引用，model/tool wrapper 恢复同一路径，不再次读取当前技能表。
- `apps/runtime-service/src/runtime_service/services/dearflow_agent/workspace/backend.py:87` 的 `prepare_custom_skills()` 将公共与自定义内容共同哈希，原子发布独立快照目录，空集合也创建正确公共快照。
  快照完整性不符或目录缺失明确失败；只读 backend 拒绝 write/edit/delete/upload；Docker 使用 readonly mount。
- `apps/runtime-service/src/runtime_service/services/dearflow_agent/agent.py` 移除线程永久 freeze，在每个执行图中装配快照 middleware；schema 探测不访问技能数据库。
- `apps/runtime-service/src/runtime_service/services/dearflow_agent/tools/skills.py` 改为 upload_skill/update_skill/set_skill_enabled/delete_skill；只读 review 不写证据，移除 evaluate/publish/revoke。
  远端 import 保留固定 GitHub commit、下载限额和同一存储校验；所有写工具继续受权限与 HITL 控制。
- `capabilities.py` 及四份内置 skill-creator/skill-reviewer/find-skills/surprise-me 指令和 provenance 同步新语义。

快照沿既有持久 Workspace 生命周期保留，不在技能删除时清理。首期每次访问按内容哈希校验，
50 条×1 MiB 是自定义内容上限；没有预建清理服务或第二套 Run 数据库。GraphHarbor 包未修改。
