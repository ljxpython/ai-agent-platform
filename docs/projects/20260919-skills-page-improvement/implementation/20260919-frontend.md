## 具体改动

### 1. Service 层契约全面升级（`skills.service.ts`）
- 彻底移除 `OFFICIAL_PUBLIC_SKILLS` 硬编码列表、旧 `SkillVersion` 类型及 candidate/activate/revoke 请求。
- 引入完整的强类型定义：`SkillItem`, `PublicSkillItem`, `CustomSkillItem`, `SkillDetail`, `SkillManifestItem`, `SkillContentResponse`, `DearSkillsListResponse` 等。
- 接入 7 类无会话管理接口：
  1. `getDearSkills(projectId)`: 获取公共及自定义技能列表（剥离 manifest 字段）。
  2. `getDearSkillDetail(projectId, source, slug)`: 获取技能完整元数据与 manifest。
  3. `getDearSkillContent(projectId, source, slug, path, revision)`: 获取单个文件文本正文。
  4. `createCustomSkill(projectId, packageBase64)`: 上传新建自定义技能（默认启用）。
  5. `updateCustomSkill(projectId, slug, packageBase64, expectedRevision)`: 显式覆盖更新，保留原启停状态。
  6. `toggleCustomSkill(projectId, slug, enabled, expectedRevision)`: 启停切换，返回完整更新后详情。
  7. `deleteCustomSkill(projectId, slug, expectedRevision)`: 彻底删除技能，`expected_revision` 作为 query 参数传递。

### 2. Skills 页面去会话化与组件重构（`DearAgentSkillsPage.vue`）
- **去会话化治理**：删除 `useDearGovernanceContext` 中的 threads 依赖，改用 `useWorkspaceProjectContext` 仅获取 `activeProjectId` 与 `activeProject`。顶栏彻底移除会话选择器下拉框。
- **公共目录适配**：剥离旧 `category` 依赖与分类徽标，支持基于 name、slug、description 的全文过滤；卡片展示只读状态与“查看详情”入口。
- **自定义管理体验提升**：
  - 卡片操作区提供行级启停 Switch 开关（带 loading 防抖，PATCH 成功就地替换数据）。
  - 显式“更新包”按钮：直接打开更新弹窗并自动绑定目标 slug 与当前 revision（PUT）。
  - “查看详情”按钮：滑出详情抽屉。
  - “删除”按钮：接入 `ConfirmDialog` 进行二次危险确认（DELETE 204）。
  - 导入弹窗冲突转接：当 POST 返回 409 `skill_name_conflict` 时，弹窗内提示转为覆盖更新。
- **详情抽屉（`BaseDrawer`）**：
  - 点击“查看详情”滑出抽屉，按需加载 `manifest`。
  - 左侧文件树导航：展示文件体积与可读状态（锁定标记及不可读原因 hover）。
  - 右侧正文预览：默认加载 `SKILL.md`；Markdown 文件调用 `renderMarkdown`（`html: false`）安全渲染；其他代码文本严格转义展示；遇到 409 `skill_revision_conflict` 自动静默拉取最新详情并重载当前文件。
