## 改动范围
- **影响服务：**
  - `platform-api`：PostgreSQL 项目知识库元数据持久化、动态 Scoped Token 签发、动态控制面连接
  - `runtime-service`：Thread 绑定动态解析、MCP 客户端动态装配解耦静态 JSON
  - `research/rag-anything-use`（及其远端 `sshmy2` 部署）：无状态 JWT 验签、多租户按需懒加载初始化物理目录与向量存储
- **改动级别：** 治理改动（跨多服务契约演进与生产微服务鉴权架构重构）
- **预计工作量：** 2.5 人天

## 关键决策
1. **基于共享对称密钥（HS256）的 Scoped Delegation Token 协议**：控制面动态签发有时效凭据，远端微服务纯无状态验签，避免引入跨网络分布式双写数据库，实现 0 次网络反查、0 次服务重启。
2. **物理存储与向量索引懒加载隔离**：远端 RAG 首次收到新项目的合法 Token 时，自动按命名空间 `${KNOWLEDGE_ROOT_DIR}/${tenant_id}/${project_id}/${knowledge_base_id}/` 初始化物理磁盘目录与向量 collection，实现完全隔离。
3. **向后兼容静态配置 fallback**：保留原有静态配置解析路径，既有单元测试与开发靶场 100% 保持兼容。
